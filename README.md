# Emerald Wedding

Адаптивное свадебное приглашение Амины и Мирлана. React + Vite, без серверной части.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
npm run build
```

Для проверки production: `npm run preview`.

## Данные клиента

Все имена, дата, время, тексты, адрес, ссылка 2ГИС и фотографии находятся в **src/config/wedding.js**. Дата в формате `YYYY-MM-DD` автоматически меняет календарь и день недели. Фотографии заменяются через импорты в этом файле; файлы хранятся в `src/assets/images`.

Ссылка 2ГИС ведёт на поиск указанного адреса. Замените `mapUrl` прямой ссылкой на карточку заведения, когда она будет предоставлена клиентом. Название и адрес взяты из макета; их следует подтвердить перед рассылкой.

Основные изображения заменены на новые изображения высокого разрешения, созданные встроенным ImageGen. Изображение ресторана — атмосферная иллюстрация, а не документальная фотография Riviera Hall; его можно заменить реальной фотографией заведения в config. Google Fonts загружается при наличии интернета; предусмотрен системный serif fallback.

## Конверт

Конверт открывается только по нажатию на печать. Анимация длится 4,9 секунды, а при `prefers-reduced-motion` используется короткое затухание. При обновлении страницы вступление показывается снова. Слои сохраняют постоянный z-index: задняя часть → письмо → передняя часть. Клапан складывается и скрывается, затем письмо выходит на 77% своей высоты, а конверт опускается. Hero начинает появляться на 3,65 секунде одновременно с растворением сцены.

## GitHub и Vercel

```bash
git add .
git commit -m "Create emerald wedding invitation"
git remote add origin <URL вашего репозитория>
git push -u origin main
```

В Vercel выберите **Add New → Project**, импортируйте репозиторий GitHub и выберите preset **Vite**. Build command: `npm run build`, Output directory: `dist`. Переменные окружения не требуются. Нажмите Deploy. Последующие push автоматически публикуют обновления.

Компоненты секций находятся в `src/components`, общие стили — в `src/styles/main.css`.

## Проверка обновлённой версии

Production-сборка проверена в Chrome на 320, 375, 390, 430, 768 и 1440 px. Дополнительно проверены короткие экраны 320×568 и 430×600, повторное открытие после обновления страницы, постоянный порядок слоёв, отсутствие выхода письма за экран, перекрытие Hero и envelope scene при переходе, загрузка изображений и `prefers-reduced-motion`.

Промпты и происхождение новых изображений: [docs/IMAGE_ASSETS.md](docs/IMAGE_ASSETS.md).
